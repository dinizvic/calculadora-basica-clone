# CALCULADORA BÁSICA

### DESCRIÇÃO:

Esta é uma calculadora básica que suporta operações simples entre dois valores.

### OPERAÇÕES:

- Adição;
- Subtração;
- Multiplicação;
- Divisão (INTEIRA e REAL);

---------------------------

O usuário pode usar as operações disponíveis digitando o operador correspondente a cada uma delas, ou, pode usar palavras simples como *soma* ou *adição*, por exemplo.

(NOTA: o programa será fechado caso algum valor inválido seja inserido.)

### EXECUTANDO:

Com o Python instalado, o programa pode ser acessado a partir de uma IDE ou por meio do terminal (certifique-se de estar na pasta em que o programa está localizado).

# 🧮 Calculadora Básica

## 📖 Descrição

Este projeto consiste em uma calculadora simples desenvolvida em Python, capaz de realizar operações matemáticas básicas entre dois valores informados pelo usuário.

O programa foi criado com o objetivo de praticar conceitos fundamentais de programação, como:

- Entrada e saída de dados;
- Estruturas condicionais;
- Operadores matemáticos;
- Tratamento básico de entradas.

---

## ⚙️ Funcionalidades

A calculadora suporta as seguintes operações:

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão Real
- 🧩 Divisão Inteira

O usuário pode escolher as operações utilizando:

- símbolos matemáticos (`+`, `-`, `*`, `/`, `//`)
- ou palavras-chave simples, como:
  - `soma`
  - `adição`
  - `multiplicação`
  - `divisão`

---

## ⚠️ Observações

- O programa será encerrado caso um valor inválido seja inserido.
- Certifique-se de digitar números válidos durante a execução.
