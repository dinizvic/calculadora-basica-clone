# CALCULADORA BÁSICA

### DESCRIÇÃO:

Esta é uma calculadora básica que suporta operações simples entre dois valores.

### OPERAÇÕES:

- Adição;
- Subtração;
- Multiplicação;
- Divisão (INTEIRA e REAL);

---------------------------

O usuário pode usar as operações disponíveis digitando o operador correspondente a cada uma delas, ou, pode usar palavras simples como *soma* ou *adição*, por exemplo.

(NOTA: o programa será fechado caso algum valor inválido seja inserido.)

### EXECUTANDO:

Com o Python instalado, o programa pode ser acessado a partir de uma IDE ou por meio do terminal (certifique-se de estar na pasta em que o programa está localizado).
